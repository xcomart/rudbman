Features

From the first query to the last backup.

One fast native window for the work you do against a database every day.

Any JDBC driver

Downloaded from Maven Central or picked from disk. Eight popular databases come predefined.

SQL workbench

Dialect-aware highlighting, completion, Format SQL, transactions, query history and execution plans.

Editable result grid

A virtualized grid with staged edits, BLOB and CLOB values, multiline text and WHERE filters.

ERD and query builder

Schema diagrams laid out and routed automatically, and joins dragged into SQL you can watch take shape.

Backup, restore, transfer

Replayable .sql backups, other tools' dumps restored, and tables copied between connections.

SSH tunnels

Password or key through a bastion host. Secrets stay in the OS keychain, never in a file.

Install

Up and running in a minute.

Every download carries its own Java runtime, so there is no JDK to install. From then on rudbman updates itself.

All releases → User guide → 
> winget install Xcomart.Rudbman

Windows 10 and 11, no administrator rights. The installer and a portable zip are also on the release page.

$ brew install --cask xcomart/tap/rudbman

Apple Silicon. The cask clears the quarantine flag, so the first launch just opens.

# the x86_64 linux-gnu archive from the latest release
$ tar xzf rudbman-v*-x86_64-unknown-linux-gnu.tar.gz
$ cd rudbman-v*/ && ./install.sh

Installs under ~/.local with no root. Needs glibc 2.35 or newer — Ubuntu 22.04, Debian 12 and later.
